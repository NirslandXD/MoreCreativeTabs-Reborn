## MoreCreativeTabs: Reborn

A Minecraft 
1.19.1
 port of MoreCreativeTabs: Reborn for creating and customizing creative tabs with JSON files and resource packs.

Resource pack paths remain compatible with the original `morecreativetabs` namespace.

### Build

Run `gradlew.bat build` on Windows or `./gradlew build` on Linux/macOS. The Fabric and Forge JARs are collected under `build/libs` with capitalized loader names (`Fabric` and `Forge`).
