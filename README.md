![##Information](https://cdn.modrinth.com/data/cached_images/4ffd82b9b95fe18cab8dfb34762717780e1051c7.png)
This mod allows you to create and add items to custom creative tabs, using JSON files inside resource packs. It's aimed at modpack makers and even allows you to disable access to vanilla creative tabs as well as tabs from other mods

This mod is client-side only and is very small in size with no dependencies (other than the Fabric API on Fabric), so you can easily include it inside your modpack.

![##Changes](https://cdn.modrinth.com/data/cached_images/cc38ee612d79e792b70bd6453e7d4148d640bc34.png)

- You can add a search bar to any creative tab
- Some features were deprecated and replaced with updated ones
- Items can be removed from vanilla/modded tab
- More minecraft versions(1.16.5, 1.17.1)
- New tab replacement functionality
- And more...
